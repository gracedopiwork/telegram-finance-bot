Claude vs Gemini

Panduan internal: model bisnis YFD First Aid, kuota AI, dan proyeksi skala pengguna

Dokumen: PERHITUNGAN_BIAYA_AI_CLAUDE_VS_GEMINI  |  Tanggal: Juli 2026  |  Kurs acuan: Rp 16.500 / USD

1. Ringkasan eksekutif

YFD First Aid memakai AI untuk (A) parsing transaksi bot Telegram dan (B) Doctor's Note / insight dashboard. Saat ini provider utama adalah Claude (Haiku + Sonnet). Dokumen ini membandingkan biaya dengan Google Gemini dan menjelaskan dampak model sekali bayar (lifetime) vs biaya API berulang.

Poin penting: Angka Rp 5.000/bulan per user di sistem YFD adalah plafon kuota internal, bukan tagihan Claude/Gemini ke provider. Setelah kuota habis, user tetap bisa catat transaksi (mode biasa) tanpa biaya API tambahan.

7.1 Pendapatan sekali bayar vs biaya bulanan

1 juta user × Rp 300.000 = Rp 300 miliar (one-time, bukan per bulan)
Biaya API Claude (skenario aktif): ~Rp 5,4 miliar/bulan → runway ~55 bulan (~4,6 tahun) dari pool pendapatan sekali bayar
Biaya API Gemini Lite (skenario aktif): ~Rp 500 juta/bulan → runway ~600 bulan (~50 tahun)
Tanpa langganan berulang, model lifetime akan terkuras pada skala besar + user sangat aktif. Solusi: kuota AI (sudah ada) + langganan Doctor's Note Rp 10.000/bulan.

9. Rekomendasi strategi provider

Fase Provider Alasan
Pilot (<500 user) Claude Haiku Stabilitas JSON + aturan konteks sudah teruji; biaya masih kecil (puluhan ribu/bulan)
Growth (500–10.000 user) Claude Haiku + kuota ketat Pertahankan akurasi; pantau biaya bulanan di dashboard Anthropic
Scale (10.000+ user) Gemini Flash-Lite (parse bot) Hemat 80–90%; perlu uji ulang akurasi kategori konteks
Doctor's Note premium Claude Haiku/Sonnet Insight berkualitas; frekuensi rendah (1×/bulan) → biaya tetap kecil

10. Keputusan yang perlu disetujui klien

  1. Lifetime mencakup dashboard angka + kuota AI terbatas — bukan AI unlimited.
  2. Doctor's Note dijual terpisah Rp 10.000/bulan (cashflow berulang).
  3. FTSA Premium (Rp 50k/12 bln) tetap produk behavioral terpisah.
  4. Migrasi ke Gemini dipertimbangkan saat user aktif > 5.000 atau biaya API > Rp 5 juta/bulan.
  5. Pembayaran langganan via Midtrans otomatis (bukan transfer manual admin).
